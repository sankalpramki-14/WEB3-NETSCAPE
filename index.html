01

WHAT IS IT?

A blockchain is a shared database maintained across a network of computers.

02

HOW IT WORKS

TRANSACTION → VALIDATION → BLOCK → NETWORK

Transactions are broadcast to the network and processed according to the network's rules.

03

WHY IT MATTERS

It can allow multiple participants to share a verifiable record without relying on one central database.

!

REALITY CHECK

Blockchain is not automatically better than a conventional database. Its value depends on the problem being solved.
