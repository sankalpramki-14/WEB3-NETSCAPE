# NETSCAPE

An interactive Web3 learning experience that explores the evolution of the internet and introduces the core ideas behind Web3 through an immersive digital experience.

## Overview

NETSCAPE takes visitors on a journey from the early internet to Web3, introducing concepts such as:

- Blockchain
- Decentralization
- Cryptography
- Transactions
- Cryptocurrency
- Wallets
- Smart Contracts
- NFTs
- DAOs
- DeFi
- dApps

Rather than presenting Web3 as a collection of definitions, NETSCAPE is designed as an interactive experience where users can explore these concepts visually and interact with them.

## Experience

The journey follows:

**WATCH → UNDERSTAND → EXPLORE → INTERACT → DISCOVER → CONNECT**
